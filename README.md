###  Sobre Mim

Estudante de **Análise e Desenvolvimento de Sistemas**. 

Sou focado em resolução de problemas por meio do código e da análise de dados. Venho construindo pipelines end-to-end de dados, dashboards interativos, aplicações desktop full-stack e automações. Além disso, possuo vivência prática com suporte técnico, diagnósticos de rede e rotinas operacionais baseadas em ITIL.

*  **Formação:** Tecnólogo em Análise e Desenvolvimento de Sistemas (ADS) — Uninter previsão de conclusão **DEZ 2027**.
*  **Foco Atual:** Análise de Dados (Pandas, SQL, Matplotlib, Plotly) & Desenvolvimento com Python, JS e Java.
*  **Ambiente de Trabalho Favorito:** VS Code (com Jupyter Notebook), Figma e Pacote Office.
